# SheetNest 架构与数据

知华科技（上海如静知华信息科技有限公司） · <https://www.zhuatech.cn/> · 商业咨询微信 zhuatech / zhuatech2。

## 边界与数据路径

浏览器Vue页面经同源Nginx调用Spring MVC；Spring Security保护会话和CSRF；NestService处理身份范围、指定岗位、整方案版本、计算与状态事务；JPA读取MySQL，Flyway负责版本迁移。NestingEngine为无数据库的整数算法，输入单规格板与矩形需求，输出布局树和面积账。数据库、Java、Nginx分别健康检查，仅前端8132映射回环。

## 算法与整数模型

板材减去四边留边形成根节点。每次在自由叶片左上角安放一个零件，按纵向优先或横向优先用完整切缝拆成子板，继续选择叶片；不合并自由叶片。每个CUT节点包含当前位置、宽高、方向、绝对切点和切缝；PART／OFFCUT是叶节点。先序表是逻辑树展开，不含设备控制和留边切割工艺。

需求采用4种排序×2种分割，共8个有界候选；比较更多排入件、较少板数、较低切缝面积及稳定策略序。不是全局优化或价格优化。允许旋转才尝试宽高交换，输入变化不沿用旧计算。尺寸为0.1mm整数，面积为0.01mm²的long，界限内不溢出。最大30种300件、30张板、50次计算；数据库参数限制100—1000方案，成功UUID请求键最多10000个。

每板零件＋切缝＋余料＝可用矩形面积；全部使用板的零件＋切缝＋余料＋留边＝整板面积。零板时利用率为0，未排入需求明确保留。余料没有库存／物性／可售含义。

## 事务、独立性与重试

写事务READ_COMMITTED，以基础部门行锁序列化业务和身份授权更新，随后刷新当前账号及角色；再验证读权限、范围、写权限／指定岗位。UUID指纹包括当前人、路径和完整输入。只有授权仍有效的同一请求可返回原响应，改内容或换人不能复用。删除需求的重试通过显式父方案校验，避免删除后绕过授权。

所有业务写入检查整方案版本并递增一次；不同请求携带相同旧版本时只有一个成功。同一UUID响应按首次成功快照返回，即使后续业务已推进，不自动改写旧响应。该参考实现通过共享锁保证清晰一致性，未提供分布式高吞吐能力。

创建、方案修改、零件修改、计算均保留编辑人。复核人不得为任何历史编辑人或执行人；登记人不得为历史编辑人。必须是同负责部门、启用且具有job.read及对应权限的账号。纯登记角色的ALL范围不扩展到其他方案。

当前输入摘要与计算输入摘要一致，布局摘要以JSON内容复算；批准保存组合摘要。实物送审以申报结局与所有人工结果生成报告摘要；封存再次验证批准与报告摘要，持久化最终摘要及结局。没有外部密钥签名，拥有数据库管理权的人可能同时修改数据及摘要。

## 初始化与版本

V1／V2由Flyway执行，JPA ddl-auto=validate。仅账号为空时初始化目录和admin；重启保留所有数据。UTC存储微秒，网页固定上海时区。升级新增SQL版本并在独立环境先验证备份恢复；不得编辑已发布迁移或关闭校验。
