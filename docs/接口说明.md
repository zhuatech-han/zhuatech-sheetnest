# SheetNest 接口说明

知华科技（上海如静知华信息科技有限公司） · <https://www.zhuatech.cn/> · 商业咨询微信 zhuatech / zhuatech2。

同源/api，会话Cookie，写入使用GET /auth/csrf返回的header与token。仅CSRF引导、登录及/actuator/health允许匿名；健康无业务数据。响应不含口令散列，非声明JSON字段拒绝400。毫米尺寸BigDecimal精确转0.1mm整数，整数计数拒绝小数。

| 方法与路径 | 输入／响应 |
|---|---|
| GET /auth/csrf；POST /auth/login | 令牌；username/password登录 |
| GET /auth/me；POST /auth/logout；POST /auth/password | 安全身份；退出；oldPassword/newPassword，改密使会话失效 |
| GET /options | 范围内部门、材料类型、安全账号与权限、工作空间名 |
| GET /jobs | search/status/page/size/sort；size1—50，page0—1000，sort newest/oldest/reference；rows/total |
| POST /jobs；PUT /jobs/{id} | requestKey/version/reference/name/departmentId/category/material/width/height/margin/kerf/maxSheets/instructions/reviewerId/operatorId |
| GET /jobs/{id} | 方案、零件、当前布局、历史摘要、实际结果、最近200条轨迹与可操作标志 |
| POST /parts；PUT /parts/{id} | requestKey/version/jobId/code/name/width/height/quantity/rotation |
| POST /parts/{id}/delete | requestKey/version/jobId/note；仅草稿，删除后重试先验证父方案 |
| GET /revisions/{id} | 父方案授权后的不可变输入与历史布局 |
| POST /jobs/{id}/commands/{action} | requestKey/version/note；submit-report另需outcome FINISHED或STOPPED |
| POST /results | requestKey/version/jobId/partId/good/scrap/notCut/note；人工数量，使用整方案版本 |
| GET /jobs/{id}/report.json；GET /jobs/{id}/parts.csv | export权限及父方案范围；CSV UTF-8 BOM、公式转义、未登记留空 |
| GET /dashboard；GET /audit | 统计；范围内最多500条审计 |
| GET/POST /admin/{type}；PUT/DELETE /admin/{type}/{id} | ALL范围admin，type仅users/roles/departments/menus/permissions/dictionaries/settings |

命令：calculate、submit、approve、return-plan、start、acknowledge、submit-report、return-result、close、cancel。所有命令验证状态、实时范围、指定岗位与整方案version；UUID指纹绑定当前人和完整输入。不得把缓存旧成功响应作为当前状态依据，应重新读取详情。取消仅限实物登记开始前。

管理输入按类型选择有限字段：用户username/displayName/password/roleId/departmentId/enabled；角色name/scope/permissions；部门name；菜单name/nameEn/permissionCode/position/enabled；权限name；字典type/code/name/nameEn；参数value。不提交实体id、密码散列或无关字段。用户编辑密码留空保留。已注册权限、菜单、参数不可创建，内建资源删除与最后管理员受保护。

主要错误：401 UNAUTHENTICATED；403 FORBIDDEN／OUT_OF_SCOPE／INDEPENDENT_REVIEW_REQUIRED／ASSIGNED_OPERATOR_ONLY；400 INVALID_INPUT／INVALID_DIMENSION／INVALID_DESIGN／INVALID_COUNTS／INVALID_OUTCOME；409 STALE_VERSION／FROZEN／UNPLACED_PARTS／INCOMPLETE_RESULT／ACKNOWLEDGEMENT_REQUIRED／SNAPSHOT_CHANGED／REQUEST_KEY_REUSED／CONFLICT。其他有界目录／版本上限返回409，客户端应显示实际错误并刷新；不包含SQL和凭证。

API算法布局的unit为0.1mm，width/height/x/y/at/kerf均为ticks；面积字段为0.01mm²。普通方案及零件DTO width/height/margin/kerf为mm。调用者须按字段上下文转换，不能把绘图ticks误作毫米。结果是逻辑排样估算，不是CNC执行格式。
